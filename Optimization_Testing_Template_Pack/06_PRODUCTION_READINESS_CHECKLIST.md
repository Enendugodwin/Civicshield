# Production Readiness Checklist

## Infrastructure

- [ ] CPU capacity validated from benchmark.
- [ ] RAM capacity validated from peak workload.
- [ ] Storage latency validated.
- [ ] Network capacity validated.
- [ ] Monitoring enabled.
- [ ] Alerts configured.
- [ ] Backup/restore tested.
- [ ] Capacity limits documented.

## Application

- [ ] Health checks exist.
- [ ] Timeouts configured.
- [ ] Retries bounded.
- [ ] Connection pools bounded.
- [ ] Queues bounded.
- [ ] Caches bounded.
- [ ] Structured logs enabled.
- [ ] Sensitive data protected.

## Testing

- [ ] Unit tests pass.
- [ ] Integration tests pass.
- [ ] Functional tests pass.
- [ ] Security tests pass.
- [ ] Regression tests pass.
- [ ] Load test passes.
- [ ] Stress test completed.
- [ ] Recovery test completed.

## Performance

- [ ] P95 budget met.
- [ ] P99 budget met.
- [ ] Throughput target met.
- [ ] CPU target met.
- [ ] Memory target met.
- [ ] Error-rate target met.

## Release

- [ ] Change approved.
- [ ] Rollback procedure validated.
- [ ] Baseline stored.
- [ ] Known limitations documented.
